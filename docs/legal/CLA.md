## 7. How to accept

Put this sentence in the description of your first pull request, with your GitHub login:

> I have read the Ferris IDEA Contributor License Agreement, version 1.1, and I accept it for all my
> contributions. — @your-login

Your acceptance covers your later contributions too, until a new version of this agreement is
published and you accept it. In addition, sign off each commit (`git commit -s`), which confirms the
[Developer Certificate of Origin 1.1](https://developercertificate.org/) for that commit.

The project records each acceptance in [CLA_SIGNATURES.md](CLA_SIGNATURES.md) before it merges the
pull request. No bot with write access to the repository is involved.
