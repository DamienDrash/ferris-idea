# Improvements over the reference

Weaknesses observed in the reference IDE are not reproduced 1:1. Each one gets an entry here
with the observed behaviour, how IDECraft behaves instead, and how that is verified. The
improvement is also stated as a deviation in the spec it belongs to.

Rules: an entry cites an observation (`OBS-nnnn`) as evidence; it describes behaviour in our
own words; "Status" follows the spec (`proposed` → `specified` → `implemented` with test; "logic" = core tested, not yet wired to drivers/UI).
