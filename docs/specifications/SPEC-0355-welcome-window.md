## Purpose
Without an open project Ferris IDEA shows a window of its own from which the user opens a recent
project, starts a new one, opens a folder or clones a repository, and adjusts the look, keymap
and plugins before any project is open — instead of the bare folder chooser of SPEC-0094 v9.

## Behaviour

### When it appears
1. **Start without a project.** Ferris IDEA started without a folder (`ferris-idea launch`, the app
   bundle from Finder, the Dock or Spotlight, SPEC-0282 behaviours 6 and 7) shows the Welcome
   window when it has no project to reopen: "Reopen the last project at start-up" is off
   (SPEC-0337 behaviour 2) or no recent project exists any more. With a project to reopen that
   project opens as before. `ferris-idea ui <folder>` and `ferris-idea launch <folder>` open the folder
   (or a file's project, SPEC-0094 behaviour 18) directly; the Welcome window does not appear.
   [GEN, OBS-0095]
2. **After the last project window.** When Close Project, Close All Projects or a window's close
   button closes the last project window (SPEC-0094 behaviours 6 to 11), the Welcome window
   appears. [OBS-0095]
3. **One at a time.** A process has at most one Welcome window; showing it again brings it to the
   front. [GEN]
4. **Leaving it.** Opening a project from it closes it; so does any other project window that
   opens while it is shown (an agent, `ferris-idea open`, a file from Finder). Closing it with its
   close button or ⌘W while no project window is open quits Ferris IDEA, as cancelling the folder
   chooser did; with a project window open it only closes. ⌘Q quits as everywhere (SPEC-0261).
   [GEN]

### The window
5. **Shape.** A window of its own, 800 × 650 pt at first, centred, resizable down to 640 × 480 pt,
   with the system's window buttons and the title "Welcome to Ferris IDEA". A column on the left holds
   Ferris IDEA's app icon, the name "Ferris IDEA" and the version, then the sections Projects,
   Remote Development › SSH (v3: under the group heading "Remote Development", the entry "SSH"),
   Customize, Plugins and Learn, each with an icon; the column's foot holds the gear menu
   (behaviour 21). The content of the chosen section fills the rest. Projects is chosen at first.
   [OBS-0095]
6. **Look.** Colours come from the theme in use (SPEC-0060; by default `Ferris IDEA Dark` or
   `Ferris IDEA Light`): the brand accent marks the chosen section, the focus, the primary button and
   the project squares (ADR-0018); text, separators and hover use the theme's tokens. Icons are the
   bundled open icons or Ferris IDEA's own; nothing of the reference's logos, icons, colours or
   texts is used (ADR-0009). The window follows a change of theme at once. [ADR-0009, ADR-0018]

### Projects
7. **Actions.** Above the list: a search field and the buttons New Project, Open and Clone
   Repository. Open shows the system's folder chooser and opens the chosen folder like the
   project popup's Open… (SPEC-0094 behaviours 2 and 18). New Project and Clone Repository show
   the forms of SPEC-0094 behaviours 13 and 14 in the content area with every rule of those
   behaviours unchanged: only HTTPS and SSH addresses without credentials, a new folder in a
   folder that exists, Git never asks, one hour at most, progress with Cancel, one clone at a time,
   the new folder opens in a project window of its own that asks whether to trust it (SPEC-0278).
   Their Location starts at the folder that holds the most recent project, else the home folder.
   Escape or Cancel goes back to the list. The forms keep long paths inside their fields, drop
   an error once a field is edited, show their own hint, and a project New Project made is
   trusted without the question (SPEC-0094 v10 behaviours 13a and 14). [GEN, SPEC-0094]
8. **The list.** The recent projects of SPEC-0094 behaviour 3, most recent first, at most 25. Each
   row has a square with the project's initials (SPEC-0061 rule) in the accent colour, the
   project's name, its folder with `~` for the home folder, and the Git branch checked out in it
   (read from the repository's `HEAD`; nothing without a repository or on a detached head). A click
   or Enter opens the project; a project already open in a window brings that window to the
   front (SPEC-0094 behaviour 2). Without recent projects the content says so under the actions.
   [OBS-0095, SPEC-0094]
9. **Missing folders (deviation, IMP-0502).** A project whose folder no longer exists (deleted,
   moved, on a drive that is not attached) stays in the list, greyed and marked "missing", until
   the user removes it; it cannot be opened, and trying says so in the line under the list. Every
   row offers "Remove from list" (shown on the selected or hovered row); removing only edits the
   list, never the folder. [GEN, SPEC-0094 v10 behaviour 3]
10. **Search.** Typing filters the rows by name and folder, ignoring case, as one types; Escape
    empties the field. Without a match the list says so. [OBS-0095, GEN]
11. **Keyboard.** The search field has the keys when the window opens. ↓ and ↑ move the selection
    through the shown rows and wrap; the keymap's first-row and last-row keys (⌥↑/⌥↓ in the
    macOS keymap) and, while the search is empty, Home and End go to the first and last row
    (SPEC-0275 v19 behaviour 47); Enter opens the selected project; ⌘⌫ removes it from the list; ⌘N is New
    Project, ⌘O Open; ⌘1 to ⌘5 choose the sections in their order (v3: ⌘2 is SSH, ⌘3 Customize,
    ⌘4 Plugins, ⌘5 Learn; v1 had ⌘1 to ⌘4 without SSH). Everything that has a key can
    also be clicked. [GEN]

### Remote Development
12. **SSH (v3).** The section Remote Development › SSH opens SSH hosts' folders as remote projects
    with Ferris IDEA's one SSH stack: the recent remote projects and the connection of SPEC-0317
    behaviours 1 to 5, the host list of SPEC-0121 behaviour 1, every rule of ADR-0025 unchanged
    (the system `ssh` in batch mode, keys only through the SSH agent or the files the SSH
    configuration names, strict host keys, no password or passphrase typed into Ferris IDEA, the
    shared options with the post-quantum key exchange). [OBS-0095, SPEC-0317, ADR-0025]
    - **12a. The list.** The heading "Recent SSH Projects", a search field and the button New
      Project (primary). The rows: first the recent remote projects (SPEC-0317 behaviour 1) whose
      host is an SSH host — an alias or `[user@]host[:port]` — most recent first, each with a square
      with the folder's initials (SPEC-0061 rule) in the accent colour, the folder's name and
      `host:folder`; then the hosts of the SSH configuration (`~/.ssh/config` and the files it
      includes, patterns left out), each with its alias, what `ssh -G` resolves (`user@hostname`,
      `:port` when not 22) and the mark "host". Reading the configuration connects to nothing.
      Recent projects of containers, WSL or paired hosts are not listed here; they stay in a
      project window's Remote Development…. Without any row the content says that SSH projects
      appear here after the first connection and offers New Project. [OBS-0095, SPEC-0121,
      SPEC-0317]
    - **12b. Search and keys.** As behaviours 10 and 11: typing filters by name, host and folder,
      ignoring case; ↓ and ↑ wrap; the first-row and last-row keys; Enter opens the selected row;
      ⌘⌫ removes the selected recent project from the list; ⌘N is New Project while the section is
      shown. Everything that has a key can also be clicked. [GEN]
    - **12c. Opening a recent project.** A click or Enter on a recent project opens its folder as a
      remote project exactly as Remote Development… does (SPEC-0317 behaviours 3 to 5, the same
      code): the line under the list names the steps, Escape stops and ends whatever was started on
      the host; when the project window is there the Welcome window closes (behaviour 4). A
      project already open in a window brings that window to the front. A failure — unknown or
      changed host key, login refused, host not reachable, no post-quantum key exchange, a folder
      that is gone — is said in that line with what to do (SPEC-0121 behaviour 2); the list stays.
      [SPEC-0317]
    - **12d. New Project (connect).** New Project shows a form in the content area: Host (an alias
      of the configuration, a host name or an IPv4 address), User (empty: the configuration's or the
      system's), Port (empty: the configuration's, else 22), and a fixed line: "Authentication: your
      SSH agent or the keys your SSH configuration names (IdentityFile); Ferris IDEA never asks for a
      password. Host keys must already be known." Tab moves between the fields; Enter or Connect
      checks them — host and user hold letters, digits, `.`, `_` and `-` and do not start with `-`,
      the port is a number from 1 to 65535 — and connects as `[user@]host[:port]`; Escape or Cancel
      goes back to the list. A field's error goes once the field is edited. Enter or a click on a
      configured host's row shows this form with the alias filled in. [OBS-0095, GEN]
    - **12e. Choosing the folder.** Once connected, the content shows the folder chooser of
      SPEC-0317 behaviour 2 (the host's home folder, folders to go into, a path field, `..`), headed
      with the host, without the Remote Host window's file actions (no terminal, new file, rename,
      delete, backend); its first row "Open <folder> as a remote project" opens the folder shown as in
      12c. Escape while it opens stops it; Escape otherwise goes back to the list. [SPEC-0317]
    - **12f. Remove.** "Remove from list" (shown on the selected or hovered recent row) or ⌘⌫ takes
      the entry out of the recent remote projects file (host and folder only, private to the user,
      SEC-10); nothing on the host and nothing in the SSH configuration changes. Configured hosts
      have no Remove: they belong to the user's SSH configuration, which Ferris IDEA never writes.
      [GEN, SPEC-0317]
    - **12g. Host keys (deviation, IMP-0044).** The reference's connection dialog offers to accept an
      unknown host's key. Ferris IDEA never accepts a host key itself: an unknown key is refused with
      "connect once in a terminal (`ssh <host>`), check the fingerprint and accept it there", a
      changed key with its own warning; nothing is sent in either case. [ADR-0025, SPEC-0121]
    - **12h. No key file, no password (deviation).** The form has no field for a key file and none
      for a password: keys come from the SSH agent or an `IdentityFile` of the SSH configuration,
      so the reconnection of SPEC-0317 behaviour 14 uses the same key without Ferris IDEA storing a
      path or a secret. The reference's further connection kinds behind New Project's arrow and its
      per-connection buttons (refresh, stop, settings) are not offered: Ferris IDEA starts no backend
      that would run on its own, and Settings of a connection are the SSH configuration.
      [ADR-0025, OBS-0095]

13. **Dev Containers (deviation).** Ferris IDEA has no Dev Containers feature (SPEC-0119 leaves them
    out), so the Welcome window has no such section. [SPEC-0119]

### Customize
14. **Theme.** The themes of SPEC-0060, one click chooses one for every window at once and saves
    it, as the theme popup does. "Sync with OS" (SPEC-0131) follows the system's light or dark
    appearance; while it is on, a chosen theme becomes the theme for the system's current
    appearance. [SPEC-0060, SPEC-0131]
15. **Editor.** The editor colour scheme under the heading "Editor color scheme", spelt as in
    Settings and everywhere else in the interface (v4) — the theme's own or one of the bundled
    schemes (SPEC-0337 behaviour 4) — and the editor font size with − and + in whole points inside the
    bounds of SPEC-0129. "Compact mode" (SPEC-0165) stands where the reference offers a font size
    for the whole interface, which Ferris IDEA does not have (deviation). [SPEC-0337, SPEC-0129,
    SPEC-0165]
16. **Keymap.** The keymap in use is named; "Configure…" opens Settings › Keymap. [SPEC-0105]
17. **Import Settings… and All Settings….** Import Settings… asks for an exchange file and shows
    its import preview; nothing changes before the user confirms there (SPEC-0105 v9 behaviour 14,
    SPEC-0303). Without a project only files of the user's own settings are taken (kinds
    `settings`, `keymap` and `theme`); a file of another kind (run configurations, connections)
    carries project data and is refused with a note to open a project first. All Settings… opens the Settings dialog (SPEC-0105) over the Welcome window;
    pages that belong to a project say so and change nothing. Every change in this section is the
    same change, in the same files, as in Settings; the Welcome window keeps nothing of its own.
    [SPEC-0105, SPEC-0303]

### Plugins
18. **Plugins.** The installed plugins (SPEC-0126) with their name, version and whether they are
    enabled, disabled or cannot load; "Manage Plugins…" opens Settings › Plugins with install
    from disk with review, enable, disable and remove. The section's entry in the column shows the
    number of installed plugins. Nothing is fetched from a network. [SPEC-0126, OBS-0095]

### Learn
19. **Learn.** Entries for Ferris IDEA's own material: "Keyboard Shortcuts" opens Settings › Keymap
    (local); "Documentation", "Release Notes" and "Report a Problem" open the address shown on the
    entry (Ferris IDEA's public repository) in the system's browser. Nothing is fetched to show the
    section and no address is opened without the user's click. No accounts, no courses or videos
    of third parties, no learning project. [ADR-0007, OBS-0095]
20. **Nothing else (ADR-0007).** The Welcome window has no account or sign-in, no telemetry, no
    advertising space, no update check and nothing about licences or trials; it opens no network
    connection by itself. [ADR-0007]

### Gear menu
21. **Gear.** The gear at the foot of the column opens a menu with All Settings…, Import
    Settings…, Keymap… and Plugins…; ↑/↓ and Enter choose, Escape closes it. [OBS-0095]

### Agents
22. **MCP tool `welcome` (deviation, IMP-0503).** `action`:
    - `list_recent` (default): the recent projects with `path`, `name`, `exists` and `branch`,
      most recent first, missing ones included. Needs the right `recent-projects` (SPEC-0094
      behaviour 23); without it the call is refused with "not granted" and no folder. The tool
      writes one line to the agent log with the number of entries, never their paths.
    - `remove_recent` with `path`: `dry_run` (default true) names the entry that would go; a real
      removal needs `recent-projects` and `settings`; the tool's own log line holds no path (the
      line every changing call gets keeps the arguments the agent gave, SPEC-0053 v7 behaviour
      11). A path not in the list is refused.
    - `open_recent` with `path`: the folder must be in the list and exist. `dry_run` (default
      true) names it; a real call needs `recent-projects` and `ui` and opens it as a click does.
      The project's own MCP route then follows the usual rules; no right carries over.
    - `list_ssh` (v3): the rows of behaviour 12a — `recent` with `host`, `folder` and `name`, most
      recent first, and `hosts` with `alias`, `user`, `hostname` and `port` as `ssh -G` resolves
      them; nothing is connected. Needs `recent-projects` (the folders lie on other machines);
      the log line holds the counts only.
    - `remove_ssh` (v3) with `host` and `folder`: `dry_run` (default true) names the entry; a real
      removal needs `recent-projects` and `settings`, and the tool's log line holds no host or
      folder. An entry not in the list is refused.
    - `open_ssh` (v3) with `host` and `folder` of the list: `dry_run` (default true) names it and
      the rights a real call needs: `recent-projects`, `ssh`, `run` and `ui` (as
      `remote_project_open` of SPEC-0317 behaviour 20 plus the window). A real call opens it as a
      click in the section does, also while only the Welcome window is open, and answers with the
      remote project's state or the reason it did not open. Other folders of a host open with
      `remote_project_open`.
    - `show`: shows the Welcome window (or brings it to the front); needs `ui`.
    `show`, `open_recent` and `open_ssh` are served by the window over HTTP only; through `ferris-idea mcp`
    (stdio) they are refused with "no window". Known limit: while only the Welcome window is
    open, Ferris IDEA serves no project over HTTP (SPEC-0221), so no agent is connected then.
    [ADR-0008, SPEC-0053]

### Startup animation
23. **Startup animation (v2).** Ferris IDEA shows a short animated brand sequence of its own while
    start-up work still runs before the first window (Welcome or project) can be shown:
    - **When.** Only when started from the app bundle or `ferris-idea launch`, never for
      `ferris-idea ui`, `ferris-idea ui --selftest`, `ferris-idea open`, `ferris-idea mcp` or other commands.
    - **Window.** A borderless window of 480 × 160 pt in the middle of the screen with rounded
      corners and no window buttons; it takes no focus, offers nothing to click and is neither a
      project window nor the Welcome window.
    - **Order.** The splash opens first; the rest of the start-up work goes on as soon as the
      splash has drawn its first frame, and after at most 50 ms if no frame comes (a window not
      on a screen draws none), so the first window is never held back by more than that.
    - **End.** The moment the first window has drawn its first frame the splash fades out over
      150 ms and closes; it never stays longer than 1.5 s in all, the fade included, also when
      start-up takes longer (then the fade starts at 1.35 s). The animation only advances while
      the start-up work leaves the main thread free; a start that keeps it busy shows fewer of its
      steps, and an instant one only the fade.
    - **Storyboard** (the project owner's reference video of 2026-11-18 serves only as a
      storyboard; no video file is part of the application). Ferris IDEA draws the sequence itself
      from the brand's own vector paths in `docs/design/assets` (`idecraft-horizontal.svg` for the
      symbol, the wordmark's paths and their layout with 4.5 units between the crab and the
      wordmark (v5; 12 units between bracket and wordmark before), the wordmark's paths being those
      of `idecraft-wordmark.svg`; `idecraft-symbol-dark.svg` for the background; all three
      generated by `scripts/brand-assets.py`), embedded at build time, on `background-primary`
      (`#2E3440`). The horizontal logo (109 × 32 units, v5; 160.8 × 32 before) is scaled to fit the window with a clear space of 8 units on every side
      and drawn at the screen's scale, so it is sharp at any scale:
      1. 0–0.45 s: the symbol's crab (`foreground-primary`, `#ECEFF4`), centred in the window,
         is built on its grid (v5): its rows of square cells appear one after the other from the
         top, each in an equal share of the time, and each row grows outwards from the symbol's
         vertical axis to both sides at once, easing in and out; complete, it is exactly the
         master's cells. Before v5 the Ferris IDEA bracket was drawn here as one stroke.
      2. 0.45–0.65 s: the cursor bar appears in `accent-primary` (`#88C0D0`) and blinks once
         (off from 0.52 to 0.58 s).
      3. 0.65–1.1 s: the symbol moves left to its place in the horizontal logo (0.65–0.9 s,
         easing out) while a mask reveals the wordmark ("Ferris" `#ECEFF4`, "IDEA" `#88C0D0`; v5) from
         left to right (0.72–1.1 s); the mask's left edge follows the symbol, so no part of the
         wordmark shows behind it. No letter morphing, no cross-fades.
      4. Then the horizontal logo rests, cursor shown, until the first window is ready, within the
         cap of 1.5 s above.
    - **Reduce Motion.** When the system asks to reduce motion (macOS: Accessibility › Display ›
      Reduce Motion) the final horizontal logo is shown still, for as long as the start-up work
      runs and never longer than the cap, and goes without a fade.
    - **Setting.** `appearance.startup_animation` in `settings.toml`, Settings › Appearance ›
      "Startup animation" (on by default); switched off, nothing is shown and the start-up work
      runs at once. Agents read it with `ide_settings` and change it with `set_ide_settings`
      (`startup_animation`, dry run first and the `settings` right, SPEC-0129); a change counts
      at the next start.
    - **Nothing else.** Without the brand's paths (they cannot be read) nothing is shown. It uses
      only Ferris IDEA's brand (ADR-0009: own splash), no sound, no network, no telemetry.
    - The start time measured for F-001 (OBS-0001) must not grow by more than the animation's
      fade.
    [ADR-0009, GEN]
24. **Long paths (v4).** A project's path under its name in the list takes the room the row
    leaves it. A path that does not fit is shortened in its middle at folder boundaries: its start
    and as many of its last folders as fit, joined by "…" (`/private/tmp/…/night/web`), the end
    preferred over the start. The project's folder name always stays, so projects in the same long
    folder can be told apart; only a folder name too long by itself is cut in its own middle.
    Before v4 the path was cut off at its right end. [GEN; OBS-0102 W2]

## Known deviations from the reference
- Missing folders stay in the list, greyed with Remove, instead of the reference's behaviour,
  which was not observed with a missing folder (IMP-0502).
- Everything the window does for recent projects is also an MCP tool with the rights of
  SPEC-0053 (IMP-0503).
- Learn opens nothing on the network without a click and offers no account, course or learning
  project (IMP-0504); the reference shows tiles for a course that needs an account.
- No interface font size, language and region or colour-blindness adjustment (behaviours 15 and
  Out of scope); compact mode instead of the interface font size.
- No Dev Containers section; Remote Development has only SSH (v3).
- SSH: Ferris IDEA never accepts an unknown host key itself (12g, IMP-0044); no key file or password
  field (12h); no further connection kinds or per-connection refresh, stop and settings buttons;
  recent projects of containers, WSL and paired hosts stay in Remote Development… of a project
  window (12a).
- The Plugins section shows the installed count, not available updates, because Ferris IDEA does not
  look for updates on its own.
- The gear menu holds only the four settings entries.
- A project New Project made a moment ago (only `.git` in it) opens trusted, without the trust
  question (SPEC-0094 v10 behaviour 14, window check A16 NP2).
