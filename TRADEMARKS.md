# Name and logo

**Status:** statement of intent of the licensor, Damien Frigewski, 2026-11-14. "Ferris IDEA" is not
a registered trademark, and no trademark search was made. This page says how the project wants its
name and logo to be used; it claims no rights beyond those the law gives without registration.

An earlier release of the symbol, wordmark, logo and app icon under the project's former licence
(2026-11-07, still named in the release notes of v0.10.0) was withdrawn on 2026-11-16, before the
project was published ([ADR-0032](docs/adr/0032-source-available-licence.md)). This page alone
applies to them.

## Policy

The name **Ferris IDEA**, the symbol, the wordmark, the horizontal logo, the app icon, the avatar and
the social preview (`docs/design/assets/`, `packaging/icons/`) identify this project. They are not
covered by the licence in [`LICENSE.md`](LICENSE.md): all rights in them are reserved. The PolyForm
Shield License contains no trademark terms, so this page states the rules.

You may, without asking:

- use the name in plain text to refer to this project, truthfully: "built with Ferris IDEA", "a
  plugin for Ferris IDEA", "based on Ferris IDEA", "compatible with Ferris IDEA";
- show the unmodified logo when you write or speak about the project (an article, a talk, a
  review), following the rules for size, clear space and colour in the brand guidelines;
- keep the name and icon in an unmodified build you compile for yourself or your team.

You need the project owner's written consent to:

- distribute a modified version under the name Ferris IDEA, a name that can be confused with it, or
  with its logo or app icon — a fork that is passed on needs its own name and its own icon;
- use the name or logo in the name, logo, domain or account name of another product, company or
  service;
- use them in a way that suggests the project endorses, sponsors or is affiliated with you;
- put them on merchandise.

If you pass on a changed copy, say that it is changed and that it is not the original Ferris IDEA.

How to ask: see "Asking the licensor for another licence" in [`LICENSING.md`](LICENSING.md).
