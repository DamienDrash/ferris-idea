# ADR-0001: Project name `rust-ide-lab`

- **Status:** superseded by [ADR-0010](0010-name-idecraft.md) · 2026-10-31 (the rejection of `intellijcraft` still stands)
- **Context:** The preferred name was `intellijcraft`. "IntelliJ" is a JetBrains
  mark; JetBrains forbids even plugins from carrying "IntelliJ" in their name
  (Marketplace Approval Guidelines). A public IDE named `intellijcraft` would use
  a sign similar to the mark for identical goods (§ 14 Abs. 2 Nr. 2/3 MarkenG).
  The project brief names `rust-ide-lab` as the alternative for exactly this case.
- **Decision:** Repository, product and crate prefix use `rust-ide-lab` /
  `ridelab`. JetBrains names appear only descriptively in documentation.
- **Consequences:** No rename later; no trademark exposure in name, binaries or UI.
  `DamienDrash/rust-ide-lab` was available on 2026-10-30.
- **Detail:** legal analysis, section 7.
